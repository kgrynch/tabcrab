Tab Crab Options

General

Duplicate Tab Reuse

When enabled, the existing tab is moved to the new tab's window and position, focused, and the new duplicate is closed. Only exact HTTP/HTTPS URL matches are considered.

Domains also match their subdomains. In the default “all except” mode, leave this blank to apply to every eligible site.

Smart Group Rules

Define custom group aliases. One line per group, using: Group Name = domain1.com, domain2.com, *.example.com

Keyboard Shortcuts

You can manage these shortcuts by navigating to chrome://extensions/shortcuts.

Open Tab Crab: Ctrl+Shift+K

Gather All Tabs: Ctrl+Shift+L

Sort Current Window: Ctrl+Shift+J
